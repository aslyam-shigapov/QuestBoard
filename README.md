## 💡 Идея

Люди ставят цели и хотят их выполнять, но часто бросают — потому что это скучно.
**QuestBoard** делает выполнение привычек похожим на игру:

- 🗂️ **Доски** — тематические наборы квестов (спорт, учёба, чтение)
- ⚔️ **Квесты** — ежедневные задания с разной сложностью и наградой XP
- 🏆 **Ачивки** — достижения за прогресс («Первые шаги», «Марафонец», «Легенда»)
- 📈 **Уровни и XP** — прогресс пользователя растёт с каждым выполненным квестом
- 💬 **Чат доски** — общение участников в реальном времени

## ✨ Фичи

### Основные

- ✅ Регистрация, вход, выход, сброс пароля через email
- ✅ Вход через **Яндекс** (OAuth2)
- ✅ Создание/редактирование/удаление **досок**
- ✅ CRUD для **квестов** внутри досок
- ✅ Отметка квестов как выполненных (+ XP пользователю)
- ✅ Профиль пользователя с **уровнем, XP, аватаркой, био**
- ✅ **Избранные доски** (через сессии, работает для анонимов)
- ✅ **Переключатель темы** (светлая/тёмная через куки)

### Продвинутые

- 🌐 **REST API** на Django REST Framework
- 📚 **Swagger / Redoc** автодокументация API
- 💬 **WebSocket-чат** для каждой доски (Django Channels + Redis)
- 🎲 **Management-команда `fill_db`** для заполнения БД тестовыми данными
- 🐳 **Docker + docker-compose** (PostgreSQL + Redis + Django)
- 🧪 **22 pytest-теста** (модели + API)
- ⚙️ **GitHub Actions CI** — автозапуск тестов при push

## 🛠 Стек технологий

**Backend:**
- Python 3.12 / Django 6.1
- Django REST Framework 3.18
- drf-spectacular (Swagger/OpenAPI 3.0)
- Django Channels 4.3 (WebSockets)
- Django Allauth + dj-rest-auth (OAuth2)
- pytest + pytest-django (тестирование)

**Базы данных:**
- PostgreSQL 15 (основная БД)
- Redis 7 (channel layer для WebSockets)

**Инфраструктура:**
- Docker + Docker Compose
- GitHub Actions (CI)
- Daphne (ASGI-сервер)

**Хранилище зависимостей:**
- requirements.txt

## 🚀 Быстрый старт через Docker

### Требования

- **Docker Desktop** (Windows/macOS) или **Docker Engine** (Linux)
- Скопированный репозиторий

### Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/aslyam-shigapov/QuestBoard.git
cd QuestBoard

# 2. Создать .env-файл с секретами (по образцу)
cp .env.example .env
# отредактируй .env — впиши свои SMTP-данные, OAuth-ключи

# 3. Запустить контейнеры
docker compose up -d --build

# 4. Создать суперпользователя
docker compose exec web python manage.py createsuperuser

# 5. (Опционально) Заполнить БД тестовыми данными
docker compose exec web python manage.py fill_db
